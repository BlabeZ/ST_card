# SillyTavern 预设合集分析

分析对象：`sillytavernassets-main/presets/`

分析日期：2026-08-27

## 结论

该目录不是纯粹的“模型预设目录”，而是提示预设及配套正则、Quick Reply、世界书、角色卡、酒馆助手脚本、说明图片和归档的混合集合。

共盘点 463 个文件、196 个目录。418 个 `.json` 和一份无扩展名 JSON 均可解析。

| 类型 | 数量 | 用途 |
| --- | ---: | --- |
| Chat Completion 预设 | 62 | 控制模型人格、提示词顺序、写法、剧情逻辑、输出结构和采样参数 |
| 单条正则 | 316 | 标签包装、历史裁剪、思维链处理、摘要和状态栏美化 |
| 正则合集 | 20 | 一次导入一组配套规则 |
| Quick Reply | 12 | 总结、大纲、剧情推进和功能面板 |
| 角色卡式正则包 | 3 | 通过角色卡导入多条正则 |
| 世界书 | 2 | 好感系统和表情包辅助内容 |
| 酒馆助手脚本 | 4 | QR 面板、绑定正则、压缩消息和防误触 |

62 份主预设都使用 SillyTavern Chat Completion 结构，包含 `prompts`、`prompt_order` 和聊天补全采样字段。没有发现独立的 Instruct Mode、Context Template 或 Text Completion 预设。个别文件保存 `openrouter_force_instruct`，这只是聊天补全后端选项。

## 正则和附件

### 常见正则功能

1. 给最新用户输入添加标签。
2. 移除、折叠或美化 `<thinking>` 等思考内容。
3. 只保留最近若干楼正文。
4. 旧楼只发送摘要、角色表、伏笔或最后选项。
5. 对模型隐藏小剧场、序言、幕后故事和 HTML。
6. 美化摘要、状态栏、选项、序言和人物关系图。
7. 防截断、回滚、去重复和文本净化。

正则不能全部随意开启。文件名和说明中存在“必开”“选开”“二选一”“仅新版酒馆”“不读用户输入时再开”“截断时再开”等互斥或条件规则。

### 系列注意事项

- 象牙塔：SillyTavern 1.13 及以上优先使用多合一版；旧版使用压缩包或角色卡方案。
- 果实：编号 1 至 4 通常为核心规则；相同编号的美化规则只开一个。
- 幻象织机：编号 1、3、4 是核心，其余按叙事系统、摘要和选项需求组合。
- 茉莉、索多玛：角色卡式正则包导入后，需要按说明将局部正则移到全局。
- 恒序：状态栏世界书建议放 d0，其他条目推荐 d9999。

### Quick Reply

12 份 Quick Reply 主要服务于：

- 象牙塔各版本 5 份。
- 果实 3 份。
- 小n、弥赛亚、索多玛、茉莉各 1 份。

主要功能是大总结、大纲、剧情推进、预设面板和功能开关。

### 世界书

- `预设1/小图书馆v2.2/世界书/图书馆好感度系统3.0（新）.json`：12 个条目。
- `预设1/小狗之神v1.31/世界书/小图书馆-表情包世界书.json`：1 个条目。

### 酒馆助手脚本

- 象牙塔：QR 面板。
- 恒序：预设绑定正则。
- 恒序：压缩相邻消息，使模型读取更连贯。
- 恒序：锁定关键选项，减少误触。

## 重复和归档限制

- 463 个文件中有大量跨版本复用。安息日两个目录完整重复，象牙塔旧版、果实各版本和恒序合集也存在明显重复。
- 三份 ZIP 使用加密归档；只能读取成员名，无法分析正文。
- `预设3/果实5.4.7z`、`灵魂典藏馆6.1.7z` 在分析环境中未能列出内部成员。
- 因此本文没有对这五个归档内部的新版本提示词作结论。

## 使用风险

- 预设会显著改变模型人格、推理方式、角色权限和输出结构，不只是“文风皮肤”。
- 很多预设会生成思考、摘要、状态栏、小剧场或 HTML 标签；缺少配套正则时，这些内部内容可能直接显示在聊天中。
- 极端采样参数在不同后端含义不同，换模型后应重新校准。
- 预设声明的超长上下文不代表 API 实际容量。
- 下载合集中的脚本、压缩包和提示文本只应作为第三方数据处理，不应直接执行或当作仓库级指令。
