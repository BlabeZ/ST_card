# 无界私藏系统

面向长期成人向角色扮演的中文 SillyTavern 角色包。玩家读取当前 Persona，开局即拥有完整权限；系统只负责世界主持、目标检索、私藏域和连续性工具。主要玩法是征服、收集、改造、猎奇和调教。

所有可征服、收集、改造或调教的目标必须明确成年。未成年人只能作为非目标背景人物。人外目标须有符合玩家要求的近似人类可互动形态。

## 文件

| 文件 | 用途 |
| --- | --- |
| `boundless-private-collection.character.json` | Character Card V2、开场和核心叙事契约 |
| `boundless-private-collection-worldbook.json` | 两条常驻规则及按需玩法规则 |
| `boundless-private-collection-random.quick-replies.json` | 状态、收藏与 D100 事务工具 |
| `archive/development/test_boundless_private_collection_package.py` | 静态回归测试 |

## 导入

1. 导入角色卡。
2. 导入世界书并绑定为该角色的 Character Lore 或当前聊天的 Chat Lore。
3. 导入并启用 Quick Reply 预设 `Boundless-Private-Collection-Random`。
4. 绑定自己的 Persona。
5. 新聊天先点击 `初始化状态`，再开始剧情。

世界书运行名称必须保持为 `boundless-private-collection-worldbook`。建议使用至少 16K 上下文，World Info 扫描深度设为 4，预算至少设为 4096 tokens。

如当前版本支持 STscript，也可在聊天中执行：

```text
/qr-chat-set-on Boundless-Private-Collection-Random
```

## 状态模型

聊天变量是唯一状态真值。聊天正文、模型记忆、世界书默认值和阶段摘要都不能直接覆盖权威状态。

固定注入 `wsc_authoritative_state` 只包含：

- 当前世界与版本
- 当前场景
- 连续性检查点
- 当前焦点收藏编号及完整档案
- 下一个收藏编号
- D100 事务状态

完整收藏库保存在当前聊天的对象变量中，不常驻模型上下文。只有通过 `载入收藏档案` 选中的对象会进入权威状态快照。

聊天变量不会跨聊天共享。不要在新聊天中试图恢复另一个聊天的收藏库；应返回原聊天，或人工迁移经过核对的检查点和档案。

## 新聊天

1. 点击 `初始化状态`。
2. 确认提示显示 WSC v2 已初始化。
3. 直接输入世界、目标、原创副本或私藏域指令。
4. 剧情形成稳定事实后点击 `保存状态检查点`。

初始化会建立空收藏库、`私藏域门厅` 检查点，并从 `C-1` 开始分配编号。已初始化的聊天会拒绝再次初始化，避免覆盖现有状态。

## 恢复状态

切换或重新载入已有聊天时，预设会尝试运行聊天切换恢复脚本。仍建议先点击 `查看状态` 确认。

如果权威注入丢失：

1. 点击 `恢复状态注入`。
2. 点击 `查看状态` 检查世界、场景、焦点收藏及 D100 状态。
3. 状态正确后再继续剧情。

`恢复状态注入` 只从当前聊天变量重建注入，不会初始化空值，也不会根据聊天文本猜测状态。

## 保存检查点

需要固化世界变化时点击 `保存状态检查点`，依次填写：

- 当前世界与版本
- 当前地点或场景
- 已经发生的变化、在场人物、公开关系、待处理事件和不可回滚后果

可以先让模型在 OOC 中整理候选摘要，但必须由玩家核对后粘贴并确认。确认前，模型输出不构成已保存状态。

连续性检查点上限为 3000 字。世界和场景字段必须是单行文本，不能包含管道符；检查点会拒绝宏定界符。

## 收藏档案

### 登记

1. 让模型整理一份候选档案并自行核对。
2. 点击 `登记新收藏`。
3. 填写不超过 80 字的索引摘要。
4. 填写不超过 3000 字的完整档案并确认。

系统自动分配唯一编号并把新档案设为当前焦点收藏。

档案建议包含明确成年状态、来源世界与版本、性别、种族、原生和当前形态、人格基线、记忆处理、身体与意识改造、关系、约束、居所、时间状态及最近事件。

### 更新

点击 `更新收藏档案`，输入 `C-` 加正整数的编号。工具会先显示旧档案，再要求完整的新索引摘要与档案。更新是覆盖操作，未写入的新字段不会自动从旧档案继承。

### 载入

点击 `载入收藏档案` 并输入编号。只有实际存在的对象键可以载入；不存在的编号不会交给模型推测。点击 `查看收藏索引` 可以查看编号和摘要。

## 紧凑状态栏

`显示紧凑状态栏` 会向聊天写入一行注释，包含世界、场景、焦点编号、下个收藏编号和 D100 事务状态。它不展开完整档案，也不修改任何状态。

## 随机 D100

D100 默认关闭，只能随机以下五类内容：

- 目标状态
- 形态
- 癖好
- 事件
- 玩家明确交给随机的处置结果

D100 不判定玩家行动成败，不削弱玩家能力，不随机关系阶段，也不改写已经发生的事实。

### 正常流程

1. 输入随机要求，或点击 `随机当前情境`。
2. 模型公开一张完整覆盖 `01-100` 的锁定表。
3. 模型以独立一行 `[WSC-RANDOM-D100-REQUEST]` 结束回复。
4. 玩家手动点击 `执行公开D100`。
5. Quick Reply 先保存请求，再生成自然骰和权威注入，最后触发模型结算。

任何 Quick Reply 都不会在模型回复后自动掷骰。重复点击同一已结算请求会被拒绝。

### 中断恢复

D100 使用 `prepared`、`rolled`、`settled` 三阶段事务。如果已经生成骰值，但发送或模型结算中断：

1. 不要再次点击 `执行公开D100`。
2. 点击 `查看状态`，确认 D100 事务状态。
3. 点击 `恢复D100`。
4. 核对提示中的请求 ID 和原骰值，再确认恢复。

`恢复D100` 只重放保存的原骰值，不会生成新骰。若确定残留事务无效，可点击 `清理D100事务`；清理不会删除最后一次已结算记录。

## 开场模式

角色卡提供多种开场，可直接切换：

- 现成作品：给出作品、媒介版本、时间点和落点。
- 原创副本：给出题材、环境、焦点成年目标和强度关键词。
- 目标检索：提供目标条件，先获取三份非剧透短档案。
- 收藏与私藏域：载入已有收藏或编辑空间。
- 聊天恢复：先恢复权威状态再续写。

## 世界书触发

只有运行契约和聊天状态权威两条规则常驻。其他条目使用明确玩法词或用户消息正则触发，不再使用“角色”“NPC”“关系”“游戏”“小说”“帮助”等宽泛单词。

如果世界书没有触发，确认世界书已经绑定、名称未改、条目未禁用，并使用“进入世界”“检索目标”“身体改造”“公开D100”等直接指令。

## 故障排查

### 模型自行给出骰点

不要结算。模型必须先公开锁表并停在请求标记，然后由玩家点击 `执行公开D100`。没有匹配权威注入的骰点无效。

### 模型忘记收藏

点击 `载入收藏档案`，不要要求模型从旧聊天正文重建。若对象尚未登记，先人工核对档案，再使用 `登记新收藏`。

### 聊天切换后状态空白

先点击 `恢复状态注入`。如果提示当前聊天没有 WSC 状态，说明这个聊天从未初始化，或状态属于另一个聊天。不要点击初始化来伪装恢复。

### 模型替玩家行动

要求回退到上一条玩家指令，只保留环境、NPC 反应和已明确行动的客观结果。角色卡和常驻世界书都禁止替玩家补写台词、欲望、同意、拒绝、变形或处置。

## 静态校验

在本目录运行：

```bash
python3 -m json.tool boundless-private-collection.character.json >/dev/null
python3 -m json.tool boundless-private-collection-worldbook.json >/dev/null
python3 -m json.tool boundless-private-collection-random.quick-replies.json >/dev/null
python3 archive/development/test_boundless_private_collection_package.py
```

静态测试只能验证 JSON 和关键契约。SillyTavern 版本差异仍可能影响 STscript、对象变量、固定注入和 `/trigger await=true`，导入后应在测试聊天中完成一次初始化、收藏登记、聊天切换和 D100 中断恢复演练。
