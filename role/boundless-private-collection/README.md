# 无界私藏系统角色包

这是一个面向长期成人向角色扮演的中文 SillyTavern 角色包。玩家读取当前 Persona，开局即全能；系统只负责世界穿越、副本主持、目标检索、私藏域与收藏连续性。主要玩法是征服、收集、改造、猎奇和调教，少量情感只在具体关系中形成。

系统不是可攻略 NPC，没有身体、成长线或高于玩家的权限。NPC可以在局部反抗、欺骗和逃跑，但不能封印、削弱或夺走玩家能力。

## 文件

| 顺序 | 文件 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| 1 | `boundless-private-collection.character.json` | Character Card V2、开场、示例对话与核心提示 | 必需 |
| 2 | `boundless-private-collection-worldbook.json` | 全能权限、目标、世界、收藏、改造、R18G 与随机规则 | 完整体验必需 |
| 3 | `boundless-private-collection-random.quick-replies.json` | 按需 D100、自动续写与手动后备按钮 | 使用随机玩法时必需 |
| 4 | `README.md` | 导入、玩法与故障排查 | 推荐阅读 |

## 导入

1. 在角色管理界面导入 `boundless-private-collection.character.json`。
2. 在 World Info 或 Lorebook 中导入 `boundless-private-collection-worldbook.json`。
3. 保留世界书运行名称 `boundless-private-collection-worldbook`，并绑定为该角色的 Character Lore、Additional Character Lore 或当前聊天的 Chat Lore。
4. 在 Quick Replies 扩展中导入 `boundless-private-collection-random.quick-replies.json`，启用预设 `Boundless-Private-Collection-Random`。
5. 建立并绑定自己的 Persona。角色卡不会固定玩家姓名、性别、外貌和身体。
6. 开启新聊天，从世界、目标、原创副本或私藏域中任选一种指令开始。

建议使用至少 16K 上下文，把全局 World Info 扫描深度设为 4，预算设为至少 4096 tokens。不同 SillyTavern 版本的 Character Lore 入口名称可能不同。

如果当前版本支持 STscript，也可在聊天中启用 Quick Reply 预设。

```text
/qr-chat-set-on Boundless-Private-Collection-Random
```

## Persona

卡片会读取已绑定 Persona，已有信息不会重复询问。最小 Persona 可以只写以下内容。

```text
姓名或称呼：
性别与代词：
常用外形：
叙事偏好：
```

玩家拥有自由变形权限，因此 Persona 不需要罗列所有可能形态。聊天中明确下令即可切换，系统不得擅自替玩家变形。

## 常用开局

可以直接输入自然语言，无需固定命令。

```text
进入《作品名》的某个版本，从指定时间点开始，不写入当地身份。
```

```text
检索三名符合这些条件的成年目标，只给非剧透档案。
```

```text
生成一个以人外、封闭设施和身份差为关键词的原创副本。
```

```text
打开私藏域，建立一间观察室和一处独立生态区。
```

```text
启用随机玩法，为当前目标随机形态、癖好和事件，按这个顺序逐项掷骰。
```

## 世界与目标

- 支持原创世界及已公开的动漫、游戏、影视和小说世界。
- 点名现成作品时，最好给出媒介版本和时间点，避免电影、漫画、游戏或重启版本混写。
- 原作剧情只是无人干预时的默认轨迹。玩家介入后，人物关系、伤亡、改造和世界后果不会为了回到原作而重置。
- 目标性别不限，可为人类、类人、人外、异形、超自然存在和猎奇种族。
- 参与成人互动的角色必须明确为成年人，并具备近似人类的可互动形态。
- 指定时间点中的未成年原作角色不会进入成人目标池。需要相关人物时，应明确要求建立年龄、经历、心智、身体和社会身份均成熟的成年平行版本。

## 私藏域

私藏域是玩家绝对控制的随身维度。系统可以按指令建立居住区、生态区、展示区、训练区、观察区、实验与改造区、医疗复原区、静滞档案及其他自定义区域。

正式收集对象会取得唯一编号。档案持续记录来源世界、成年状态、种族、原生与当前形态、人格和记忆处理、身体与意识改造、关系、约束、居所、静滞状态及最近事件。

系统默认只显示发生变化的字段。可以随时要求“显示 C-007 完整档案”或“列出所有处于静滞的收藏”。

## 随机 D100

随机模块默认休眠，只在玩家明确声明需要随机玩法时启动。骰子只生成以下内容。

- 目标状态
- 目标形态
- 目标癖好
- 当前事件
- 玩家明确交给随机的处置结果

骰子不判定玩家行动成败，不会削弱全能权限，也不会修改已经发生的事实。

完整流程如下。

1. 玩家输入随机要求，或点击“随机当前情境”。
2. 模型根据要求建立一张覆盖 `01-100` 的公开临时表。
3. 模型以独立一行 `[WSC-RANDOM-D100-REQUEST]` 结束回复。
4. 隐藏 QR 用 SillyTavern 客户端 `{{roll 1d100}}` 生成自然骰，注入权威数据，发送可见结果并触发续写。
5. 模型核对消息 ID 与客户端注入，只按公开区间结算一次。
6. 多个随机项目逐项处理。前一个结果结算后，模型才建立下一张表并请求下一枚骰子。

“执行公开D100”是手动后备按钮。若当前 SillyTavern 版本没有在模型请求后自动运行隐藏 QR，可点击该按钮。按钮会拒绝没有请求、请求格式错误或已经消费的旧请求。

Quick Reply 使用当前聊天变量 `wsc_last_request_id`、`wsc_last_request_text` 和 `wsc_last_roll`，并用临时注入 `wsc_random_authority` 证明骰点来自客户端。变量只存在于当前聊天，不会跨聊天继承。

## R18G 与连续性

角色包允许成人内容、血腥、断肢、身体恐怖、残酷改造和其他 R18G 表现。模型会尽量保持身体位置、损伤、器官、形态、改造、复原与时间连续性。

复原需要指定回到哪个时间点或档案版本。默认只修复点名损伤，不撤销未提及的改造、记忆和关系。复制体使用子编号，除非玩家明确要求共享意识或同步记忆。

实际输出尺度仍受所用模型、API 提供方、预设和本地设置影响。角色卡不能覆盖模型服务本身的限制。

## 故障排查

### 模型自行给出骰点

不要结算。确认 Quick Reply 预设已启用，让模型重新公开随机表，并以 `[WSC-RANDOM-D100-REQUEST]` 停笔。只有同时存在匹配系统注入的客户端结果才有效。

### 自动骰没有运行

点击“执行公开D100”。最后一条可见消息必须是模型回复，并以独立请求标记结束。部分 SillyTavern 版本会阻止模型生成结束后的自动二次触发，手动按钮用于兼容这种情况。

### 世界书没有触发

确认世界书已绑定，名称仍为 `boundless-private-collection-worldbook`，全局 Scan Depth 至少为 4。五条核心规则是常驻条目，其余条目通过“私藏域”“现成作品”“目标”“改造”“随机玩法”等关键词触发。

### 模型替玩家行动

在 OOC 中要求回到上一条玩家指令，只保留环境、NPC反应和客观结果。角色卡与世界书都禁止替玩家补写台词、欲望、同意、拒绝、变形和处置。

### 长聊天遗忘收藏状态

要求系统输出当前对象完整档案，将关键档案保留在聊天上下文或阶段摘要中。SillyTavern 的普通聊天不会自动把状态写入外部数据库，模型上下文裁剪后仍可能需要人工回填摘要。

## 已知限制

- 当前包已按 Character Card V2、World Info 和 Quick Reply v2 JSON 结构编写，但仍需在实际 SillyTavern 版本中检查导入和自动执行行为。
- 隐藏 QR 的自动二次触发依赖 SillyTavern 版本和生成锁行为，失败时使用可见后备按钮。
- 现成作品覆盖取决于所用模型掌握的版本资料。版本差异会影响人物时，应先明确媒介和时间点。
- 收藏连续性依赖当前聊天上下文。超长聊天建议定期要求完整档案或阶段摘要。

## 静态校验

```bash
python3 -m json.tool boundless-private-collection.character.json >/dev/null
python3 -m json.tool boundless-private-collection-worldbook.json >/dev/null
python3 -m json.tool boundless-private-collection-random.quick-replies.json >/dev/null
```
