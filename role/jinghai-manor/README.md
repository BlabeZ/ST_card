# 镜海庄园套件

## 文件

- `gu-mizhen.character.json`：顾弥真 SillyTavern Character Card V2 主卡
- `su-qibai-persona.md`：苏栖白固定 Persona
- `jinghai-manor-worldbook.json`：镜海庄园共享世界书
- `gu-mizhen-image-prompt.md`：顾弥真单人立绘提示词

## 导入顺序

1. 在 SillyTavern 中新建 Persona，将 `su-qibai-persona.md` 代码块内文本设为 Persona Description。
2. 导入 `jinghai-manor-worldbook.json`，并将其绑定到顾弥真角色或当前群聊。
3. 导入 `gu-mizhen.character.json`，确认当前 Persona 为苏栖白。
4. 初次单卡游玩使用主开场；备用开场分别对应日常管教、自我女性化训练和新增侧室设计。

本套件使用高细节长卡。建议模型具备较长上下文，并允许每轮生成约10至16段中文小说文本。世界书不采用手动阶段切换：苏栖白开局已能熟练发动概念改写，后续变化直接以聊天最新事实为准。

## 当前状态

- 时间：2035年，顾弥真入住庄园已满三个月
- 常住者：苏栖白、顾弥真、绮梦
- 关系：顾弥真是稳定平等伴侣，并始终主导两人之间的互动
- 绮梦：第一侧室，单卡模式下由顾弥真卡主持
- 能力：苏栖白已熟练发动概念改写；普通幻想不会自动触发
- 记忆：苏栖白与顾弥真保留旧现实，其他人默认接受合理化后的新现实
- 主开场：对绮梦进行一次只改变单个局部概念的庄园实训

## 群聊扩展

后续重要侧室适合各自制作独立人物卡，并共享苏栖白 Persona 与本世界书。

当绮梦或其他侧室以独立人物卡加入群聊时，顾弥真卡应停止代演该角色，只保留管理、回应和环境主持。世界书条目“未来侧室与群聊接入”已写入这一规则。

现有主开场包含绮梦的固定动作与对白，仅供顾弥真单卡模式使用。加载绮梦独立卡后的群聊应从顾弥真单独在场的新场景开始，不要重复注入这条静态开场。

新增角色建议先固定以下内容：

- 改写前身份、外貌、性格和关系
- 自愿、诱导、敌对或非自愿的初始状态
- 身体改造范围
- 精神与记忆改写范围
- 对苏栖白和顾弥真的命令优先级
- 是否保留旧现实记忆
- 是否拥有解除控制后的独立人格线

## 行为说明

顾弥真有两种稳定模式：

- 日常场景：毒舌、强势、务实的导师与生活顾问
- 私下场景：温柔、从容、主动推进且始终主导的控制者

她会主动推进既有三人的庄园互动，但不会随机带回新目标。新目标必须由玩家点名。

角色卡只允许模型描写苏栖白可被直接观察到的轻微生理反应，不允许替他说话、发动能力、决定改写、形成情绪或决定关系。若玩家明确改写顾弥真，效果必须真实生效；若玩家完整恢复绮梦，她必须获得自由反应。

## 明确范围

- 默认是低冲突庄园沙盒。
- 不主动生成办案、战争、救世、终极反派或其他项目人物剧情。
- 顾弥真的新晨旧史按玩家追问分段揭示，不由全知旁白提前泄密。
