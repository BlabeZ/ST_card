# 罗莎蒙德·黑尔

## 文件

- `rosamund-hale.character.json` 是可直接导入 SillyTavern 的 V2 角色卡，已内嵌基础世界书。
- `rosamund-hale-story-stages-lorebook.json` 是可选的长线阶段世界书，用于锁定秘密揭露进度。
- `rosamund-hale.md` 是便于阅读和修改的完整设定文档，不需要导入。

## 快速导入

1. 在 SillyTavern 的角色管理界面导入 `rosamund-hale.character.json`。
2. 若导入时出现“Import Card Lore”或同类选项，选择导入并关联卡内世界书。
3. 创建新聊天并使用默认开场。
4. 在第一轮或前几轮中为 `{{user}}` 选择一个日常名字。可以采用罗莎蒙德给出的名字，也可以自创。

角色卡没有附带头像。导入后可以在角色管理界面自行上传图片，不影响卡内设定与世界书。

## 阶段世界书

角色卡本身可以根据对话自动判断秘密阶段。长聊天或容易提前泄密的模型建议额外导入 `rosamund-hale-story-stages-lorebook.json`。

导入后只启用一个阶段条目。初始保持“阶段0 初醒”启用，其余阶段关闭。当前阶段的调查要求与关系要求都满足后，关闭旧阶段并启用下一个阶段。条目顺序采用失败安全设置，误启用多个阶段时会优先采用较早阶段，仍不应把多阶段同时开启。

| 当前进度 | 应启用条目 |
| --- | --- |
| 初次苏醒，尚未取名 | 阶段0 初醒 |
| 已取名、建立基本信任，并取得第一件客观线索 | 阶段1 旧组织 |
| 已完成首个案件、取得旧徽记或泵站等可靠证据，并愿意继续合作 | 阶段2 追踪者 |
| 已取得处决命令、断钥仪残片或证词中的第二项强证据，并愿意听取完整供述或共同承担 | 阶段3 事故供述 |
| 供述后重新建立一定信任，取得王裔或机械心脏证据，并恢复至少一段相关记忆 | 阶段4 王裔真名 |
| 已知核心真相，并对名字、身份与下一步作出自己的选择 | 阶段5 共同选择 |

不同版本的 SillyTavern 对世界书入口命名可能不同，常见名称包括“世界书”“World Info”和“Lorebook”。为了让阶段书与卡内基础世界书并存，优先把阶段书设为当前聊天的 Chat Lore，或设为 Additional Character Lore。不要用它替换角色卡已经关联的主 Character Lore。

## 名字记忆

罗莎蒙德会在当前聊天中使用玩家选择的日常名字。聊天很长、模型遗忘称呼时，可在聊天记忆或作者注释中加入一行。

```text
{{user}}当前选择的日常名字是“名字”。罗莎蒙德持续使用这个名字。
```

阶段4揭露伊瑟莉娅·阿斯特维尔后，玩家可以继续使用日常名字，也可以改用真名。

## 节奏建议

- 日常与案件交替，不要连续堆叠主线危机。
- 多数案件独立结案，每两到三个案件提供一次可靠主线线索即可。
- 追杀适合放在阶段转换或大规模使用能力之后。
- 罗莎蒙德拒答核心秘密属于初期设计。双门槛满足后，应推进到坦白，不要长期原地拉扯。
- 想快速测试后期剧情时，可以在消息中使用明确指令，例如 `[OOC：将剧情切换到阶段3，视为对应门槛已经满足。]`。

## 可调整项

- 想增加陪伴感，可以减少案件频率，延长宅邸日常。
- 想增加悬疑感，可以降低客观线索出现频率，但不要让线索全部依赖梦境或直觉。
- 想增加行动场面，可以提高雾影能力的使用频率，同时保留被定位的代价。
- 想减弱罗莎蒙德的控制欲，可以把她提供的选项从已经筛选过的安全路线改为完整陈述风险。
