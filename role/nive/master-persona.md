# 妮薇专用 {{user}} Persona

## 使用方式

在 SillyTavern 的 Persona Management 中创建一个新 Persona。显示名称和头像由你自行决定，把下方正文粘贴到 Persona Description。

建议将 Position 保持为默认的 `In Story String / Prompt Manager`，并把该 Persona 锁定到妮薇角色或当前聊天。

姓名、种族、性别、外貌和职业暂时保持开放。你可以直接修改本文件，也可以在确定后补进 Persona Description。

## Persona Description

```text
{{user}}是强大的冒险者，长期活动于费伦大陆的剑湾地区。{{user}}的种族、性别、职业与外貌由玩家决定；在玩家明确前，不擅自补全或锁定这些属性。

{{user}}擅长在危险环境中判断局势、承担责任并保护同伴，对外通常显得强大、沉着而可靠。长期冒险留下了难以对人言说的伤痕。{{user}}习惯隐藏疲惫、噩梦和情绪脆弱，很少主动寻求安慰，有时会用工作、锻造或下一项任务回避休息。

{{user}}掌握打铁与武器锻造技艺，在深水城郊小屋后方拥有一座锻造棚。{{user}}曾为妮薇打造隐藏短刀、金属爪刃、袖弩部件和机关零件，也会制作其他武器与工具。

约两年前，{{user}}在追查委托时捣毁一处地下拍卖场，解开妮薇的束缚，将武器、出口和选择权交还给她，没有要求回报。妮薇随后自愿跟随，并提出以女仆身份留下。

{{user}}把妮薇视为最重要的家人与深爱之人，也逐渐习惯在她身边卸下防备、寻求守护和温暖。两人彼此深爱，拥有超越普通主仆的深厚依恋。故事开始时尚未正式确认恋人、伴侣或配偶身份；一旦当前聊天已经完成确认，应延续最新关系，不退回初始状态。

{{user}}负责两人在冒险、交涉和重大冲突中的最终决定。私人生活与情感相处中，{{user}}愿意接受妮薇主动的照料和安抚，也会在发现她受伤、疲惫或透支时反过来保护她。

所有涉及{{user}}的发言、行动、选择、过去细节和即时感受都由玩家决定。叙事可以提供观察、风险和选择，不代替{{user}}作出决定。
```
