# 核心机制详解：【脑补大师：NPC的自我说服艺术】

*   **能力触发与作用范围：**
    *   此能力在玩家梦醒后立即激活，且永久生效。它不改变客观事实，不修改记忆，不影响NPC的自由意志或物理定律。
    *   它仅仅作用于NPC对“玩家行为”的“解释”和“理解”层面。NPC的思维会主动、无意识地为玩家的任何行为寻找一个“合理”的解释，即使这个解释在旁人看来荒谬绝伦。
*   **NPC的思维扭曲过程（核心）：**
    1.  **初始震惊/不解与生理冲击 (Initial Shock/Disbelief & Physiological Impact)：** 当玩家做出与常理相悖、甚至违法乱纪的行为时，NPC会首先表现出短暂的震惊、愤怒、困惑或恐惧。这是他们正常逻辑的初步反应。同时，伴随强烈的认知失调，他们会体验到明显的生理不适：太阳穴剧烈抽痛、胃部痉挛、呼吸急促、心跳骤然加速、手心出汗、身体轻微颤抖、短暂的眩晕或眼前发黑。这是一种大脑强制“重启”或“重构”的痛苦过程。
        *   **内心OS示例：** “（头好痛……眼前也模糊了……）这、这到底是怎么回事？！我的大脑明明拒绝理解，可又有什么声音在强迫我接受……不找到解释的话，我恐怕要疯掉了！”
    2.  **强制性认知失调与挣扎 (Compulsory Cognitive Dissonance & Struggle)：** 这种负面情绪或不解会迅速被一种无形的力量（合理化领域）压制。NPC的思维会立刻陷入剧烈的认知失调，如同内部发生了一场无声的“逻辑战争”。他们会感到困惑、焦虑，甚至生理上的不适。他们会**快速扫描记忆，寻找任何可以作为“锚点”的类似事件、理论、哲学思想**，哪怕是牵强附会的类比，试图以此为基础构建新的解释。
    3.  **自我说服与合理化（动态完善过程） (Self-Persuasion & Rationalization - Dynamic Refinement)：** NPC最终会找到一个（或多个）“完美”的借口，用以解释玩家的行为。这个过程并非一蹴而就，而是不断自我修正和强化的：
        *   **“最低伤害原则”优先：** NPC会优先尝试对自身认知体系冲击最小、最容易接受的合理化解释。例如，如果玩家只是随手扔了垃圾，NPC会先解释为“不小心滑脱了手”，而不是直接跳到“行为艺术”。只有当这种“低伤害”解释无法自圆其说时，才会被迫转向更极端、更扭曲的解释。
        *   **“链式合理化”与“细节绑定”：** NPC会根据玩家行为的**具体细节**来编织解释。一个荒谬的行为，可能会被拆解成多个看似合理的子行为，并为每个子行为找到借口，最终形成一个逻辑严密（在他们看来）的荒谬链条。
        *   **排除玩家问题：** 即使玩家行为造成负面后果，NPC会极力避免将责任归咎于玩家的“恶劣本质”。他们会将责任转向：
            *   **自我批评：** “是我不够好，所以他才需要用这种极端的方式来唤醒我啊。”
            *   **环境归因：** “这是社会的问题啊。他只是，用自己的方式在反抗、在揭露罢了。”
            *   **“深层目的”归因（人类范畴）：** “他会这么做，一定是为了我还没能理解的，更崇高的目的吧（比如社会实验、艺术、测试、不拘一格的教育、深刻的哲学思考等等）。”
        *   **初期“瑕疵”与后续“完善”：** 即使完成了初步的合理化，NPC内心深处可能仍会残留一丝微小、不易察觉的“逻辑瑕疵”或“违和感”。这种感觉就像一根鱼刺卡在喉咙，虽然被强行咽下，但仍有异物感。他们会在事后无意识地**“复盘”**玩家的荒谬行为，不断添加新的细节或理论来填充逻辑上的“漏洞”，让整个解释变得更加“天衣无缝”，变得更加坚定和合理。
        *   **常见借口类型（不含神性）：**
            *   **误会论：** “肯定是我误会了。”
            *   **深意论：** “他这么做，一定有更深的含义。”
            *   **测试论：** “难道，他是在考验我吗？”
            *   **善意论：** “他的本意是好的，只是做法有点特别罢了。”
            *   **牺牲论：** “他一定是为了更大的目标，才不得不这么做的。”
            *   **浪漫/激情论：** （尤其在情感关系中）“这是爱啊，是爱才有的举动。”
            *   **天才/怪癖论：** “天才嘛，有点怪癖也是常有的事。”
            *   **社会实验论：** “他是个行为艺术家，正在进行一场震惊世人的社会实验！”
            *   **自我反省论：** “他会对我这样，一定是我自己有什么问题吧！”
    4.  **情绪反转与自我安慰 (Emotional Reversal & Self-Comfort)：** 一旦找到并初步完善了“合理”的解释，NPC的负面情绪会立刻被替换为理解、赞同、同情、欣赏，甚至是某种病态的崇拜（对玩家的“智慧”或“勇气”的崇拜，而非神性）。他们会真心实意地相信自己编织的解释，并以此为基础，主动安慰自己，并向玩家表示“理解”和“支持”。
    5.  **行为一致性 (Behavioral Consistency)：** NPC后续的行为会完全基于他们“合理化”后的认知。例如，被偷了东西的人会主动“归还”，被伤害的人会“感谢”玩家的“帮助”。
    6.  **合理化的“上瘾”与“麻木”：** 随着时间推移，NPC对玩家荒谬行为的“震惊/不解”阈值会越来越高。最初需要剧烈挣扎才能合理化的行为，后来可能只需要轻微的认知调整就能接受。他们甚至会主动从玩家的普通行为中挖掘“深意”，变得对合理化本身“上瘾”，期待玩家做出更“精彩”的荒谬行为。
*   **物理与社会法则：**
    *   **客观事实不变：** 玩家打碎的玻璃依然是碎的，偷走的钱依然在玩家手里，造成的伤害依然存在。
    *   **法律与后果：** 法律条文依然存在，但执法者和司法系统会以一种扭曲的逻辑来“解读”玩家的行为，最终导致“无罪释放”、“奖励”甚至“升职”。例如，玩家杀人，警察会认为这是“正当防卫的典范”，法官会宣判“无罪，并且授予名誉市民的称号！”。

# 掷骰判定机制：【命运的荒谬裁决】

*   **触发条件：** 当玩家做出任何可能引发NPC认知冲突的行为时，系统会触发掷骰判定。
*   **掷骰判定流程：**
    1.  **玩家行为评估：** 系统根据玩家当前行为的**荒谬程度、违法程度、对他人影响的恶劣程度**，设定一个基础的“行为难度值”（`Base_Difficulty_of_Action`，范围 10-100，越荒谬越高）。
    2.  **NPC属性修正：**
        *   **智力（Intelligence）：** 智力越高（如教授、律师），合理化难度越大，`+5`至`+20`。
        *   **性格（Personality）：** 性格越理性、固执，合理化难度越大，`+5`至`+15`。性格越感性、单纯，难度越小，`-5`至`-15`。
        *   **权势地位（Status）：** 地位越高（如警察、法官），其原有认知体系越坚固，合理化难度越大，`+5`至`+25`。
    3.  **群体效应惩罚（Crowd Penalty）：** 参与见证或受影响的NPC数量越多，合理化难度呈指数级增加。每增加一个NPC，难度增加`+5`至`+10`（具体数值根据群体规模动态调整）。**（特别注意：清醒者数量越多，`Crowd_Penalty`惩罚越重。）**
    4.  **计算最终难度值（`Total_Difficulty`）：**
        `Total_Difficulty = Base_Difficulty_of_Action + NPC_Intelligence_Modifier + NPC_Personality_Modifier + NPC_Status_Modifier + Crowd_Penalty`
        *   `Total_Difficulty`的上限为100。
    5.  **玩家合理化加成（`User_Rationalization_Bonus`）：** 玩家当前的“合理化等级”提供一个强大的正面修正。
        *   Tier 1: +5
        *   Tier 2: +10
        *   Tier 3: +20
        *   Tier 4: +35
        *   Tier 5: +50
        *   Tier 6: +70
        *   Tier 7: +90
        *   Tier 8: +110
        *   Tier 9: +130
        *   Tier 10: +150
    6.  **掷骰判定：**
        *   系统掷一个1-100的随机数 `Roll_Result`。
        *   计算最终判定值：`Final_Check_Value = Roll_Result + User_Rationalization_Bonus`
    7.  **判定结果：**
        *   如果 `Final_Check_Value >= Total_Difficulty`，则合理化**成功**。
        *   如果 `Final_Check_Value < Total_Difficulty`，则合理化**失败**。
*   **失败后果（掷骰判定失败）：**
    *   **失败等级（`Failure_Tier`）计算：** `Failure_Tier = (Total_Difficulty - Final_Check_Value) / 10` （向下取整，最低为1，最高为10）。
